## КАК ЗАПУСТИТЬ ПРОЕКТ

```
1. Установить .NET 8 SDK: https://dotnet.microsoft.com/download
2. Открыть папку HttpMonitor/HttpMonitor в терминале
3. dotnet restore
4. dotnet run
   ИЛИ открыть HttpMonitor.csproj в Visual Studio 2022 → F5
```

> **Важно:** Если порт ниже 1024 — нужны права администратора.
> Рекомендуемый порт: **8080** или **8888**.

## БЛОК 2. ТЕСТЫ ВХОДЯЩИХ ЗАПРОСОВ
## (использовать браузер, Postman или вкладку «Клиент»)
## ═══════════════════════════════════════════════

### 2.1 GET-ЗАПРОСЫ (корректные)

**Инструмент:** браузер → `http://localhost:8080/`  
**ИЛИ:** Postman → GET → `http://localhost:8080/`

| # | Запрос | Ожидаемый ответ |
|---|--------|-----------------|
| 1 | `GET http://localhost:8080/` | HTTP 200 + JSON с полями status, totalRequests, getRequests и т.д. |
| 2 | Повторить GET несколько раз | `totalRequests` увеличивается, `getRequests` увеличивается |
| 3 | В логе сервера | Строка вида: `[HH:MM:SS] ✓ GET  http://localhost:8080/ → 200 (X.Xms)` |

---

### 2.2 POST-ЗАПРОСЫ (корректные)

**Postman:** POST → `http://localhost:8080/`  
Body → raw → JSON:

```json
{"message": "Привет, я тестовое сообщение!"}
```

| # | Тело запроса | Ожидаемый ответ |
|---|--------------|-----------------|
| 1 | `{"message": "Привет!"}` | HTTP 201 + `{"success": true, "id": "msg-0001", ...}` |
| 2 | Второй POST | id станет `msg-0002` |
| 3 | `{"message": "  пробелы  "}` | HTTP 400 — пустое после Trim |
| 4 | Вкладка «Сообщения» | Таблица показывает все сохранённые сообщения |

---

### 2.3 «КРИВЫЕ» ТЕСТЫ ВХОДЯЩИХ ЗАПРОСОВ

| # | Запрос | Тело | Ожидаемый HTTP-статус | Ожидаемое в теле ответа |
|---|--------|------|-----------------------|------------------------|
| 1 | POST | *(пустое)* | **400** | `"Request body is empty"` |
| 2 | POST | `это не json` | **400** | `"Invalid JSON"` |
| 3 | POST | `{"message": ""}` | **400** | `"must not be empty"` |
| 4 | POST | `{"text": "нет поля message"}` | **400** | `"must contain field 'message'"` |
| 5 | POST | `[1,2,3]` | **400** | ошибка разбора JSON |
| 6 | POST | `null` | **400** | ошибка разбора |
| 7 | POST | `{"message": null}` | **400** | поле пустое |
| 8 | PUT запрос | *любое* | **405** | `"Method Not Allowed"`, список allowed |
| 9 | DELETE запрос | *любое* | **405** | `"Method Not Allowed"` |
| 10 | PATCH запрос | *любое* | **405** | `"Method Not Allowed"` |
| 11 | POST | `{"message": "a", "extra": "field"}` | **201** | Успех — лишние поля игнорируются |
| 12 | POST | `{"MESSAGE": "большой ключ"}` | **400** | ключ `message` в нижнем регистре |
| 13 | POST | 1 МБ+ данных | По ситуации | Не должно падать с необработанным исключением |
| 14 | 10 одновременных POST | Стресс-тест | Все 10 должны получить ответ (многопоточность) |

**Как отправить несколько одновременных запросов (стресс-тест):**
```powershell
# PowerShell — 10 параллельных GET
1..10 | ForEach-Object -Parallel {
    Invoke-WebRequest -Uri "http://localhost:8080/" -Method GET
} -ThrottleLimit 10
```

## БЛОК 4. ТЕСТЫ ЛОГИРОВАНИЯ
## ═══════════════════════════════════════════════

### 4.1 Содержимое логов

После каждого запроса в логе должна быть строка:
```
[HH:MM:SS] ✓/⚠/✗  МЕТОД  URL → КОД (X.Xms)
```
- `✓` — код < 300
- `⚠` — код 3xx или 4xx
- `✗` — код 5xx

Для POST — в следующей строке должно быть тело запроса.

### 4.2 Фильтрация логов

| # | Выбрать фильтр | Ожидаемое поведение |
|---|----------------|---------------------|
| 1 | «Только GET» | Показываются только GET-записи |
| 2 | «Только POST» | Показываются только POST-записи |
| 3 | «Статус 200» | Только успешные |
| 4 | «Ошибки (4xx/5xx)» | Только ошибки |
| 5 | «Все запросы» | Всё отображается |
| 6 | Нет запросов + фильтр | `Найдено записей: 0` — без краша |

### 4.3 Сохранение в файл

| # | Действие | Ожидаемое поведение |
|---|----------|---------------------|
| 1 | Нажать «💾 Сохранить логи в файл» | Открывается диалог SaveFile |
| 2 | Сохранить как `my_logs.txt` | Файл создаётся на диске |
| 3 | Открыть файл | Все записи присутствуют с временными метками |
| 4 | Нажать «Отмена» в диалоге | Программа не падает |
| 5 | Сохранить в защищённую папку (C:\Windows\) | Ошибка с понятным сообщением |

## БЛОК 7. СТРЕССОВЫЕ / МНОГОПОТОЧНЫЕ ТЕСТЫ
## ═══════════════════════════════════════════════

### Тест многопоточности через PowerShell:

```powershell
# 20 параллельных POST-запросов
1..20 | ForEach-Object -Parallel {
    $body = @{ message = "Запрос #$_" } | ConvertTo-Json
    try {
        $r = Invoke-WebRequest -Uri "http://localhost:8080/" `
             -Method POST `
             -Body $body `
             -ContentType "application/json"
        Write-Host "OK: $_  -> $($r.StatusCode)"
    } catch {
        Write-Host "FAIL: $_ -> $_"
    }
} -ThrottleLimit 20
```

**Ожидаемый результат:**
- Все 20 запросов получили ответы
- Счётчик POST показывает 20
- Вкладка «Сообщения» содержит 20 записей
- Программа не зависла и не упала
